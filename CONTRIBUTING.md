# Contributing

This project is in an early research phase. Contributions are welcome for literature review, reproducible baselines, synthetic benchmark design, model implementations, and careful negative results.

Before opening a contribution:

1. Read `research/problem-statement.md` and `AGENTS.md`.
2. State whether a claim is evidence, inference, or hypothesis.
3. Use primary sources for research claims.
4. Compare methods at equal memory capacity where possible.
5. Include tests and a reproducible configuration for code changes.

Please avoid broad novelty claims or benchmark improvements that rely on giving one method additional history, slots, parameters, or compute without clearly reporting the difference.
